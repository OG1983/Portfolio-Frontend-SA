# Portfolio Personal - Shaif Arfan

Portfolio web moderno y responsivo construido con HTML, CSS y JavaScript vanilla.

![Preview](preview.png)

## 🚀 Características

- ✨ Diseño moderno con animaciones fluidas
- 📱 Totalmente responsive (móvil, tablet, desktop)
- 🎨 Gradientes vibrantes y efectos hover interactivos
- 🍔 Menú hamburguesa animado
- 📊 Secciones: Hero, Servicios, Proyectos, Sobre mí, Contacto

## 🛠️ Tecnologías

- HTML5
- CSS3 (Flexbox, Animations, Gradients)
- JavaScript (Vanilla)
- Google Fonts (Montserrat)
- Icons8 para iconografía

## 📦 Instalación

1. Clona este repositorio:
```bash
git clone https://github.com/tuusuario/portfolio-arfan.git
```

2. Abre `index.html` en tu navegador

¡Listo! No requiere dependencias ni build.

## 🎨 Personalización

### Cambiar colores principales
Busca y reemplaza en el CSS:
- `crimson` → tu color primario
- `#667eea` → color de gradientes

### Modificar contenido
Edita el HTML en las secciones correspondientes:
- Hero: línea 280
- Servicios: línea 295
- Proyectos: línea 320
- Contacto: línea 380

## 📱 Breakpoints Responsive

- Móvil: < 768px
- Tablet: 768px - 1199px  
- Desktop: ≥ 1200px
